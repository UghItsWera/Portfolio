# Personal Portfolio Website

## Overview

This is my personal portfolio website, built to showcase my projects, technical skills, and development journey across software engineering, web development, and game development.

The website brings together my professional experience, personal projects, and creative work in one place. It features a custom content management system that allows me to manage and update portfolio content, alongside a responsive interface designed for usability and accessibility.

**Live Website:** [Weronika's Portfolio](https://weronika-portfolio.duckdns.org)

## Purpose

This portfolio was developed to:

- Showcase my software engineering, web development, and game development projects.
- Demonstrate practical experience with full-stack development and database integration.
- Provide an overview of my technical skills, professional experience, and interests.
- Establish a professional online presence for recruiters, developers, and potential collaborators.
- Apply my knowledge of application development, deployment, and server configuration to a live project.

## Features

- Multi-page website with dedicated sections for personal information, projects, and other portfolio content.
- Custom content management system for managing and updating website content.
- Project showcases for websites, games, and other development work.
- Database integration for storing and managing dynamic content.
- Responsive layout designed for desktop and mobile devices.

## Architecture

The application follows an ASP.NET Core MVC structure, separating controllers, models, views, and data access.

The backend handles application logic, authentication, database operations, and contact form processing. Razor views generate the website's HTML, while CSS, SCSS, and JavaScript provide styling and interactive behaviour.

A custom administrative interface allows portfolio content to be managed without manually editing the website's source code for every content update.

## Deployment

The portfolio is hosted on an Oracle Cloud virtual machine running Linux. The ASP.NET Core application runs as a systemd service, with Nginx handling incoming web traffic and HTTPS configured for secure access.

Production configuration and sensitive credentials are kept outside the public source repository.
