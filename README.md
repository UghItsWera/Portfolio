# 💼 Personal Portfolio Website

## ✨ Overview
This is my personal portfolio website designed to showcase my projects, skills, and development journey as a Computer Science graduate and aspiring software engineer.

The portfolio serves as a central hub for my work, including machine learning projects, web development applications, and data-driven systems. It is designed to be simple, responsive, and easy to navigate, while highlighting both technical ability and project diversity.

---

## 🎯 Purpose
This portfolio was built to:
- Present my software engineering and machine learning projects in one place  
- Demonstrate practical experience with front-end development  
- Provide a structured overview of my technical skills and interests  
- Serve as a professional online presence for recruiters and collaborators  

---

## 🧠 Features
- 🧭 Multi-page navigation structure (About, Projects, etc.)  
- 📂 Project showcase section with links to GitHub repositories  
- 🎨 Responsive layout for desktop and mobile devices  
- 💡 Clean UI designed for readability and accessibility  
- 🧩 Modular structure for future expansion (new sections or pages)
